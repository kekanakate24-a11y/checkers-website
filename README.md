# Checkers Website

## Project Overview
This project is a 5-page responsive website developed for Checkers South Africa as part of the Web Development 1 module assessment. The website highlights Checkers' key offerings, Sixty60 delivery integration, Xtra Savings rewards, an interactive enquiry form, and a multi-location store locator.

## Website Sitemap & Architecture
The project contains 5 semantic HTML5 pages:

* **`index.html` (Home):** Hero banner for Sixty60 delivery, weekly Xtra Savings deals, and general value propositions.
* **`about.html` (About Us):** Overview of Checkers' history, mission statement, vision, and house brands.
* **`products.html` (Products & Deals):** Highlights retail departments (Bakery, Butchery, Dairy, Produce and Groceries ).
* **`enquiry.html` (Sixty60 Enquiry):** Interactive customer service form with text inputs, dropdown categories, and message fields.
* **`contact.html` (Store Locator):** Contact details and store operating hours for multiple branch locations.
