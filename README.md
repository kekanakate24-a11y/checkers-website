# Checkers Website

## Project Overview

This project is a five-page responsive website developed for Checkers South Africa as part of the Web Development 1 module assessment.

The website provides information about Checkers' products, departments, customer services, Sixty60 delivery service and Xtra Savings rewards programme. It also includes interactive features that improve the user experience.

**Live Website:** https://kekanakate24-a11y.github.io/checkers-website/

**GitHub Repository:** https://github.com/kekanakate24-a11y/checkers-website

## Website Pages and Architecture

The website consists of five semantic HTML5 pages:

1. **index.html – Home Page**
   - Introduces Checkers South Africa.
   - Displays the website's main promotional content.
   - Highlights Sixty60 delivery and Xtra Savings deals.

2. **about.html – About Us**
   - Provides information about Checkers.
   - Describes its history, mission, vision and values.

3. **products.html – Products and Deals**
   - Displays different supermarket departments.
   - Includes product images and promotional content.
   - Provides an interactive product search feature.
   - Includes an image lightbox for viewing gallery images.

4. **enquiry.html – Customer Enquiries**
   - Allows customers to submit enquiries about products and services.
   - Includes text fields, a dropdown selection and a message field.
   - Uses form validation and displays a temporary confirmation message after successful submission.

5. **contact.html – Store Locator and Contact**
   - Provides store location and contact information.
   - Includes a general contact form.
   - Validates the information entered and prepares an email using the visitor's email application.

## Website Features and Functionality

The website includes the following features:

- Responsive website layout for different screen sizes.
- Navigation links connecting all five pages.
- Product search functionality.
- Interactive product image gallery and lightbox.
- Enquiry form with required-field validation.
- Temporary enquiry confirmation message that disappears after five seconds.
- Contact form with validation.
- Internal links between website pages.
- Search engine optimisation improvements, including page titles, meta descriptions, headings and descriptive image alternative text.
- Lazy loading for selected product gallery images.
- `robots.txt` file to provide crawling instructions.
- `sitemap.xml` file containing the website's five main pages.

**Form submission note:** The contact form prepares an email using a mailto link. The visitor must send the email through their email application.
